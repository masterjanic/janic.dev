# Security policy

This repository holds the source of [janic.dev](https://janic.dev), a static blog.

## Reporting a vulnerability

Please do not open a public issue. Report it privately in one of these ways:

- [Open a private security advisory](https://github.com/masterjanic/janic.dev/security/advisories/new)
- Email [contact@janic.dev](mailto:contact@janic.dev)

Please include the affected URL or file and the steps to reproduce it. I aim to reply within 7 days.

## Scope

This policy covers janic.dev and this repository. Vulnerabilities in [Virtbase](https://virtbase.com) are out of scope here, so please report those to Virtbase directly.
